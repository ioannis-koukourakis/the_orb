========================
Detis Engine — Tech Demo
========================

This package is a free technical showcase for Detis Engine. It is not a full game product and it does not include the Detis game engine editor.

----------------
Running the demo
----------------

Keep the bin, engine, and content folders next to each other in this directory.

Windows
  Double-click `The Orb.bat`.

  Notes:
  If `The Orb.bat` does not launch, open the `bin` folder and run `The Orb.exe` directly.
  If SmartScreen warns that the app is from an unknown publisher, click "More info" and then "Run anyway". This occurs because early Detis Engine builds are not yet digitally signed.

Linux
  Open a terminal in this directory and run:
    chmod +x "The Orb.sh" && ./"The Orb.sh"

----------------
What is included
----------------

bin/     Runtime executable (no editor build).
engine/  Engine runtime, and license notices.
content/ Worlds, scripts, and art for this demo.
