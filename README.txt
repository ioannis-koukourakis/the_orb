Detis Engine — Tech Demo
========================

This package is a free technical showcase for Detis Engine. It is not a full game product and it does not include the Detis game engine editor.

Running the demo
----------------

Keep the bin, engine, and content folders next to each other in this directory.

Windows
  Double-click The Orb.bat, or open bin and run The Orb.exe.
  If Windows warns that the app is from an unknown publisher, the build is not code-signed yet. Choose More info, then Run anyway.

Linux
  From this folder: ./The Orb.sh (or cd bin && ./The Orb)
  If the shell script will not run, mark it executable once: chmod +x "The Orb.sh"

Logs are written to bin/log.txt on all platforms.


What is included
----------------

bin/     Runtime executable (no editor build).
engine/  Engine runtime, and license notices.
content/ Worlds, scripts, and art for this demo.
